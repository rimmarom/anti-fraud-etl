# ETL-процесс для выявления мошеннических операций

Итоговый проект курса «SQL для прикладных задач» (МФТИ, программа Data Analysis Pro).
[Описание задания](https://github.com/HaykInanc/sql_project)

ETL-процесс ежедневно загружает выгрузки банка в хранилище данных на PostgreSQL,
ведёт историю измерений в формате SCD2 и строит накопительную витрину мошеннических операций.

**Стек:** Python (pandas, psycopg2, SQLAlchemy), PostgreSQL

## Как работает процесс

Для каждого из 3 дней выгрузки:

1. **Загрузка:** транзакции (CSV), терминалы и чёрный список паспортов (XLSX) загружаются в таблицы хранилища.
2. **Архивация:** обработанные файлы переименовываются в `.backup` и переносятся в `data/archive/`.
3. **Инкремент и SCD2:** выделяются новые, удалённые и изменённые записи, обновляются таблицы истории
   (`effective_from`, `effective_to`, `deleted_flg`).
4. **Отчёт:** найденные мошеннические операции добавляются в витрину `REP_FRAUD` с новым `report_dt`.

## Признаки мошенничества

| # | Признак |
|---|---------|
| 1 | Операция при просроченном паспорте |
| 2 | Операция при заблокированном паспорте (из чёрного списка) |
| 3 | Операция при недействующем договоре |
| 4 | Операции в разных городах в течение одного часа |
| 5 | Попытка подбора суммы: более 3 операций за 20 минут, каждая следующая меньше предыдущей, отклонены все, кроме последней |

## Запуск

1. Нужен PostgreSQL со схемой `bank` (таблицы `clients`, `cards`, `accounts`).
2. Установить зависимости:

       pip install pandas psycopg2 sqlalchemy openpyxl

3. Скопировать `db_config.example.json` в `db_config.json` и указать свои параметры подключения.
4. Запустить:

       python project.py

## Результат

- В витрине `REP_FRAUD` найдено 15 мошеннических операций.
- В таблице истории терминалов 155 записей: 1 удалённая и 4 закрытые версии.
